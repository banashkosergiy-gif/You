# Бот запису на лазерну епіляцію

Telegram-бот для одного майстра: прайс, онлайн-запис на вільний час,
нагадування клієнтам і сповіщення майстру.

## Що вміє

**Клієнт**
- 💰 **Ціни**: прайс по зонах і комплексах, поради з підготовки.
- 📅 **Записатися**: обрати одну чи кілька зон (ціна й тривалість
  підсумовуються), дату й вільний час, вказати ім'я та телефон, підтвердити.
- 📋 **Мої записи**: переглянути й скасувати свої записи.
- 📍 **Контакти**: адреса, телефон, графік.
- Нагадування за 24 і за 2 години до візиту.

**Майстер (адмін)**
- Сповіщення про кожен новий запис і кожне скасування.
- `/today`, `/tomorrow`, `/week`, `/day 05.11`: записи з кнопками скасування
  (клієнт отримує повідомлення).
- `/block 05.11` / `/unblock 05.11` / `/blocked`: закрити або відкрити день
  (відпустка, лікарняний).
- `/admin`: довідка.

Бот пропонує лише той час, коли процедура цілком вміщається в робочий день
і не перетинається з іншими записами. Двох клієнтів на той самий час записати
неможливо, навіть якщо вони натиснуть «Підтвердити» одночасно.

## Налаштування

Усе змінюється у файлі [`config.py`](config.py):

| Що | Де |
|---|---|
| Процедури, ціни, тривалість | `PROCEDURES` |
| Робочі дні | `WORK_DAYS` (зараз пн–пт) |
| Робочі години | `WORK_START` / `WORK_END` (зараз 8:00–18:00) |
| Крок запису | `SLOT_STEP_MIN` (зараз 30 хв) |
| Перерва між клієнтами | `BREAK_AFTER_MIN` (зараз 0) |
| На скільки днів уперед | `DAYS_AHEAD` (зараз 14) |
| За скільки хвилин мінімум | `MIN_LEAD_MIN` (зараз 60) |

## Запуск

1. Створіть бота в [@BotFather](https://t.me/BotFather) командою `/newbot`
   і скопіюйте токен.
2. Встановіть Python 3.10+ і залежності (з кореня репозиторію):
   ```bash
   pip install -r laser_bot/requirements.txt
   ```
3. Скопіюйте `laser_bot/.env.example` у `laser_bot/.env` і впишіть `BOT_TOKEN`.
4. Запустіть:
   ```bash
   python -m laser_bot
   ```
5. Напишіть боту `/myid`, впишіть свій ID у `ADMIN_IDS` у файлі `.env`
   і перезапустіть бота. Після цього вам надходитимуть сповіщення
   й запрацюють адмін-команди.

Записи зберігаються у файлі `laser_bot/bookings.sqlite3`. Його варто
періодично копіювати як резервну копію.
